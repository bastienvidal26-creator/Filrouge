# FilRouge

Encyclopédie et carnet de suivi manga & anime, installable sur téléphone (application web progressive).

- Application : https://bastienvidal26-creator.github.io/Filrouge/
- `data/meta.json` : tendances, plateformes de streaming en France et revue de presse, mis à jour chaque semaine.
- `data/works.json` : fiches ajoutées par Claude à partir des demandes envoyées depuis l'application.

Aucune donnée personnelle n'est stockée ici : la liste, les notes et les illustrations restent sur le téléphone.
